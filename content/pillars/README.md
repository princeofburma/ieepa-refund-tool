# Content pillars

A **pillar** is a recurring theme/format on the channel. Everything we make
belongs to one. Pillars are the unit of comparison: when a piece underperforms,
compare it to *another piece in the same pillar* (see principle 3), not to the
channel average or to other channels.

## Why pillars

- "What works, do more" only works if you can see what a *like* piece did.
- Velocity is only meaningful like-for-like (same pillar, same first-week window).
- Doubling down means doubling down on a **pillar**, not a one-off.

## Registry

Add a row per pillar. Keep `Status` honest — this is where "do more / cut it"
decisions get made.

| Pillar | What it is | Core audience | Status (double-down / hold / cut) | Notes on what works |
|--------|-----------|---------------|-----------------------------------|---------------------|
| _example: tool walkthroughs_ | step-by-step product demos | existing users | hold | demos with a result in the first 30s retain best |

## Adding a pillar

1. Add a row above.
2. Note the *one principle* that makes this pillar work (from past data).
3. Tag each new piece's `00-idea.md` with its pillar so comparisons are easy.
